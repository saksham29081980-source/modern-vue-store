# Modern Vue Store

Create a modern, fully responsive e-commerce storefront exactly as requested: sticky header with brand/logo, About, Contact, Services links and distinct rounded Login button; a clean hero banner; product-card grid for Watches, Phones, and Images/Accessories using suitable placeholder images, names, prices and Add to Cart buttons; responsive 3–4 desktop columns and 1–2 mobile columns with refined hover/transition effects. Add a footer with Instagram, Facebook, X/Twitter, LinkedIn links/icons, Terms and Conditions, contact email kunalpareta123@gmail.com, and copyright. Use a clean minimal neutral visual palette with one accent color.
